# Referencias

Use esta area para guardar materiais que vao orientar visual, produto e implementacao.

## Estrutura

```text
docs/references/
  design/
    screenshots/
    inspiration/
    notes.md
  figma/
    exports/
    tokens/
    notes.md
  technical/
    scraper-sites.md
```

## Design

Coloque aqui imagens, screenshots e links de projetos que devem guiar a interface do Oghma Library.

Sugestao de anotacao para cada referencia:

```md
## Nome da referencia

- Link:
- O que aproveitar:
- O que evitar:
- Telas relevantes:
- Observacoes:
```

## Figma

Coloque exports, tokens, prints, nomes de componentes e qualquer codigo gerado pelo Figma em `figma/`.

Quando houver um arquivo ou link do Figma, vale registrar:

- Link do arquivo.
- Nome das telas principais.
- Cores e tipografia.
- Componentes reutilizaveis.
- Estados importantes: loading, vazio, erro, selecionado, download em progresso.

## Sites de novel

Use `technical/scraper-sites.md` para registrar descobertas por site:

- URL base.
- Se precisa JavaScript.
- Como listar novels.
- Como listar capitulos.
- Seletores relevantes.
- Rate limit recomendado.
- Observacoes legais ou termos de uso.
